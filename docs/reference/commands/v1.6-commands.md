# v1.6 Commands (in progress)

Status: **partial** — these commands are on `main` and will ship in v1.6.0. All v1.5 commands remain supported.

Agents should prefer Skills and the MCP discovery tools; these commands are thin projections for humans, CI and hosts without MCP.

## Capability discovery

```bash
soturail capabilities list [--json] [--locale <tag>]
soturail capabilities describe <id> [--json] [--locale <tag>]
```

- `list --json` keeps the v1 fields (`registryDigest`, `capabilities`) and adds `catalog` (`soturail.capability.catalog.v1`).
- `describe` prints the Capability Descriptor v2: surfaces, permissions, side effects, approval, trust requirements, provider candidates/availability, fallback and limitations.
- `--locale` changes human titles/summaries only; IDs, enums and paths never change.

## Skill discovery and export

```bash
soturail skills discover [--json]
soturail skills describe <name> [--resource <path>] [--json]
soturail skills export --target generic --layout portable [--out <dir>] [--json]
```

- `discover` lists bundled, project (`.agents/skills/`) and v1.5 pack skills with name/description only (level 1) plus validation issues.
- `describe` loads one skill's instructions, capability bindings and derived requirements (level 2), or one `references/`, `scripts/` or `assets/` file (level 3).
- `export --layout portable` writes Agent Skills directories and `soturail-export.json`; skills with errors or secret-like content are skipped and the command exits non-zero. `--layout flat` (default) is the v1.5 single-file export.
