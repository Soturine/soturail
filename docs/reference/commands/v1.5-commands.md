# v1.5 Command Additions

These commands extend the stable v1 surface. Existing v1.4 commands remain compatible unless noted in [Migration to v1.5](../../getting-started/migration-v1.5.md).

## Capability and governance

```bash
soturail capabilities list [--json]
soturail capabilities tools [--json]
soturail governance doctor
soturail governance evaluate --capability <id> --actor <id> [--payload <json>] [--approved]
```

`governance evaluate` uses the deterministic `NativeMinimal` provider. An unknown or approval-gated capability without approval exits nonzero. AGT/ACS reports unavailable in v1.5 and cannot authorize work.

## Change contracts

```bash
soturail contract create <id> --title <text> --intent <text> --criterion <text> [--risk low|medium|high|critical] [--check <command>] [--human-approval]
soturail contract verify <file> [--criterion-passed <text>] [--check-passed <command>] [--runtime-evidence] [--independent-review] [--human-approved]
```

Contracts are stored below `.soturail/contracts/`, bound to the workspace fingerprint, and verified without hidden command execution.

## Raw lifecycle

```bash
soturail raw status [--json]
soturail raw inspect <raw_id> --redacted
soturail raw sensitivity <raw_id>
soturail raw doctor
soturail raw purge --ttl <duration> [--dry-run]
soturail raw purge --ttl <duration> --execute --yes
```

MCP can return only redacted raw content. Exact disclosure remains a local CLI decision through the existing `expand` confirmation flow.

## MCP and architecture

```bash
soturail mcp smoke
soturail mcp serve --transport stdio
soturail self architecture --check [--json]
```

MCP serves the stable modern protocol through the official SDK and negotiates the documented legacy protocol for existing hosts. The architecture check detects control-plane drift such as an EOL Node baseline, duplicated artifact paths, raw bypasses, or unmapped MCP capabilities.
