# v1.5.0 Pre-implementation Audit

Date: 2026-08-23

Candidate: `v1.5.0`

Baseline: `v1.4.0` / `7c3be1d`

Release theme: Integrity, Governance Foundations & Verified Control Plane

## Release identity

- `package.json`, the npm registry, Git tag `v1.4.0`, changelog and native metadata were inspected.
- npm currently publishes `soturail@1.4.0`; the repository is clean and `main` matches `origin/main`.
- GitHub has a `v1.4.0` tag but no corresponding GitHub Release; `v1.1.0` is still marked latest there.
- The next compatible feature release is `v1.5.0`. No existing tag will be moved or replaced.
- `native/soturail-native/Cargo.toml` is stale at `0.2.1` and declares MIT while the repository/package use Apache-2.0.

## Current upstream baselines

- MCP stable specification: `2026-07-28`, with a stateless core and official TypeScript SDK v2 packages.
- MCP compatibility: preserve a legacy compatibility handler for existing `2024-11-05` clients while the canonical stdio entrypoint uses the official SDK.
- Node baseline: Node 22 and 24 LTS. Node 20 is EOL and will no longer be a supported release baseline.
- Rust remains optional. The TypeScript fallback remains required.

## Smallest sufficient v1.5.0 scope

The release implements the integrity and governance foundations needed to make the control-plane claim real: WorkspaceGuard, Artifact Registry/Store and envelopes, workspace fingerprints, evidence freshness, modern typed MCP, raw policy/lifecycle metadata, run manifests, capability registry, governance provider, dual gate, execution envelopes, change-contract/readiness foundations, focused adversarial tests, current architecture/security docs and release provenance gates.

Deferred items remain explicit in the implementation tracker: full AGT/ACS integration, SQLite/FTS index, broad schema migrations, full structural providers, temporal graph, vector backends, Conductor, desktop UI, integration brokers and media pipelines.

## Audit limitations

This audit establishes code and repository facts. It does not claim external provider reliability, sandbox isolation, npm/GitHub publication success, or CI success before those actions occur.
